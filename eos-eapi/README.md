# Overview
This LAB demonstrate how to use Ansible Network Collection `Arista.Eos` to build and provision fabric (EVPN/VxLAN) and tenant configuration on Arista EOS devices.

## LAB consists of following routers:
* `spine1`
* `spine2`
* `leaf1`
* `leaf2`
* `leaf3`
* `leaf4`
* `host1`
* `host2`
