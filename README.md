## Networkinglabs

This repository is a collection of hands-on networking labs, including topology definitions, configuration files, and supporting scripts.

Looking for lab descriptions, explanations, and walkthroughs?

Head over to [hotpotatorouting.net](https://hotpotatorouting.net), where you'll find the articles and technical insights accompanying these labs.

This repository provides the playground. The blog tells the story behind it.
